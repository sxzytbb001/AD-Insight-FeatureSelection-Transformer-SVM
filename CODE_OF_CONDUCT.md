# Code Of Conduct

This project follows a simple standard for collaboration: be respectful, keep
feedback technical, and assume that reproducibility and data ethics matter.

Unacceptable behavior includes harassment, personal attacks, publishing private
data, or pressuring contributors to weaken validation standards.

If a problem occurs, contact the repository maintainer through the issue tracker
or the contact channel listed on the GitHub repository. Maintainers may remove
content or restrict participation to keep the project usable and respectful.
