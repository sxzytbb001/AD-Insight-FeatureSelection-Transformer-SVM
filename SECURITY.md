# Security Policy

## Supported Versions

This repository is maintained as research software. Security fixes are applied
to the default branch.

## Reporting Issues

Do not publish private clinical data, access tokens, local dataset paths, or
unreleased model artifacts in public issues. If you find a security or privacy
problem, contact the repository maintainer privately through the contact channel
listed on GitHub.

## Data Privacy

The pipeline expects de-identified expression matrices and binary labels. Before
publishing data or trained artifacts, verify that the source dataset license and
privacy rules permit redistribution.
