the repository pipeline. It is a reproducibility snapshot for this code version,
not a guarantee that new cohorts will reproduce the same model ranking.

`external_datasets.json` because its s1/s2 label polarity was confirmed to be
reversed for this pipeline's positive/control convention.

## Recommended Thesis Wording

The fixed-panel internal OOF comparison gives the Transformer a higher point
estimate than the single SVM baseline, while nested and leave-one-cohort-out
sensitivity checks show a smaller gap. External validation is platform-dependent:
relative to the single SVM baseline, Transformer is slightly higher on
GSE109887, GSE118553, and GSE122063 by AUC, while SVM is slightly higher on
GSE48350. Some SVM ensemble variants remain higher on selected external
cohorts, so the external results should be presented as comparable rather than
uniformly superior.

Recommended claim:

> With a compact and interpretable method design, the lightweight Transformer
> reaches a classification level comparable to strong SVM baselines on
> small-sample transcriptomic AD data. Attention maps, gate weights, and gene
> interaction matrices provide additional structured evidence for interpreting
> candidate-gene relationships. External validation should be discussed
> cautiously because performance depends on platform shift and cohort annotation
> quality.

Avoid claiming that the Transformer is uniformly superior to SVM across all
external datasets.
