# Documentation

This directory contains project-level notes for reproducing and interpreting the
gene-expression classification pipeline.

## Files

| File | Purpose |
|---|---|
| [data_split.md](data_split.md) | Cohort roles, training split, external holdout split, and manifest summary. |
| [latest_results.md](latest_results.md) | Current reproducible AD case-study result snapshot and recommended wording. |
| [reproducibility.md](reproducibility.md) | Commands for testing, running pipeline stages, and refreshing result summaries. |
| [data_and_artifacts.md](data_and_artifacts.md) | Data, Git LFS, generated outputs, and open-source release notes. |

Local platform logs and temporary reports should not be committed here.
